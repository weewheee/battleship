# Battleship 🚢

A web-based implementation of the classic strategy board game **Battleship**, where you play against an AI algorithm. Made using Python 3, Flask, and JavaScript.

This is a small project for me to mess around with full stack web-development as well as probability algorithms.


## Installation

Install dependencies
```bash
pip install -r requirements.txt
```

## How to play

Start the Flask server
```bash
py app.py
```

Navigate to `http://127.0.0.1:5000` in your browser
